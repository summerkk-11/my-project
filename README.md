# 🎙️ 离线音频批量处理与转写系统 (Offline Audio Transcriber)

## 📖 项目简介
基于 Python 与 Faster-Whisper 的本地化音频处理流水线。本项目致力于解决云端 API 带来的**数据隐私泄露风险**，并针对**超长音频处理**中的效率与内存痛点提供了完整的工程化解决方案。

## 🚀 核心功能
*   **OOM 内存溢出解决**：利用 FFmpeg 脚本实现对长音频的智能切片处理，彻底解决大文件直接推理导致的内存崩溃问题。
*   **精准时间轴合并**：手写算法计算分段偏移量（Offset），实现切片字幕的完美无缝拼接，确保时间轴零误差。
*   **局域网安全传输**：搭建本地 HTTP 服务器，实现 PC 与移动端跨设备的高效安全传输，确保核心数据 100% 不出内网。
*   **全流程自动化**：支持断点续传与批处理调度，大幅提升长音频转写效率。

## 🛠️ 技术栈
*   **语言**：Python
*   **模型**：Faster-Whisper (Medium 模型)
*   **工具**：FFmpeg (音视频处理)
*   **网络**：HTTP Server (局域网通信)
