高质量识别与本地翻译
=====================

新的高质量流程不会覆盖旧的“字幕成果”目录。

输出位置：
D:\语音识别\字幕成果_高质量

每个输入文件生成三份字幕：
- 文件名_ja.srt：日语转写
- 文件名_zh.srt：简体中文翻译
- 文件名_bilingual.srt：日语与中文双语

处理指定文件：

  cd /d D:\语音识别
  python recognize_all.py "D:\语音识别\手机上传\某文件.mp3"

处理手机上传目录中的全部音频：

  cd /d D:\语音识别
  python recognize_all.py

质量模式：
- 语言：日语 ja
- 模型：large-v3
- 设备：CPU，int8，8 线程
- 关闭跨片段历史条件，禁用自动初始提示
- 注入领域热词“ご主人様”
- VAD 开启，使用幻觉静音阈值
- 15 分钟切片
- 逐词置信度和片段置信度过滤
- 重复句与领域异常词过滤
- 不可靠字幕保留时间轴并写 [无法识别]
- 中文翻译完全本地运行，不调用云端 API

配置文件：
D:\语音识别\quality_pipeline_config.json
